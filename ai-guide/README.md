# AI Between Therapy Sessions

Working draft for clinical review. Not linked from the homepage. Page includes noindex/nofollow. This is unlisted, not access-controlled.

## Edit the Content

Edit `ai-guide/content.md` in GitHub, then commit to main. The Publish Website workflow rebuilds the guide and deploys the entire website. Markdown headings and paragraphs control the content. Keep titles and headings in Title Case.

Design is separate in `ai-guide/template.html`. Build script is `ai-guide/build.py`. Generated index.html lives in the deployment artifact, not in the repository.

No analytics, forms, or external scripts are included in the guide.
