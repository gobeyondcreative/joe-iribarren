# AI Between Therapy Sessions

Working draft for clinical review. Not linked from the homepage. Page includes noindex/nofollow. Unlisted, not access-controlled.

## Edit the Content

Edit `ai-guide/content.md` in GitHub, then commit to main. The Publish Website workflow rebuilds and deploys the guide automatically. Keep titles and headings in Title Case.

Design is separate in `ai-guide/template.html`. Build script: `ai-guide/build.py`. The generated `ai-guide/index.html` is maintained automatically; edit Markdown rather than generated HTML.

No analytics, forms, or external scripts are included in the guide.
